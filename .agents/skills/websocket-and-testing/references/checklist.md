# WebSocket & Testing Implementation Checklist

Verify each invariant when modifying `src/litestar_security/websocket/`, `src/litestar_security/testing.py`, or `src/tests/`:

- [ ] **WST-01 (WebSocket Origin validation & startup enforcement)**: Ensure `RouteCompiler.receive_route` rejects `WebSocketRoute` handlers with `session_capable` mechanisms when `WebSocketSecurityConfig.allowed_origins` is empty (and rejects `csrf_required`), and `extract_websocket_handshake` enforces a single canonical `Origin` in `allowed_origins` for cookie credentials plus canonical validation of any `Origin` header presented (`4403`, `origin_denied`).
- [ ] **WST-02 (Connect-token bindings & reserved query-parameter rejection)**: Bind digest-only `WebSocketConnectAuthorization` records to `(connect_token_id, digest, subject_id, security_epoch, route_name, origin, restrictions, policy_fingerprint, issued_at, expires_at)` with TTL `<= maximum_connect_token_ttl` (`<= 2m`), consume atomically once, revalidate `current_security_epoch`/`route_name`/`origin`/`policy_fingerprint`, apply `restrictions` in `_merge_connect_token`, and unconditionally reject `RESERVED_QUERY_PARAMETERS` (`4401`).
- [ ] **WST-03 (Live WebSocket revocation, refresh, & outage close codes)**: Ensure `supervise_websocket_lifetime` and `WebSocketCloseCoordinator` close active sockets once on credential expiry (`4401`, `credential_expired`), `WebSocketRevocationSource` signals (`4401`, `credential_revoked`), `AuthorizationSnapshotRefresher` / guard denial (`4403`, `authorization_denied`), or revocation/refresh/epoch outages (`1013`, `verification_unavailable`).
- [ ] **WST-04 (Unimported `litestar_security.testing` boundary `R5`)**: Never import `litestar_security.testing` from runtime modules (enforced by Ruff `TID251` and `ban-relative-imports = "all"`); verify `uv run python tools/check_import_boundaries.py` passes (`'litestar_security.testing' not in sys.modules` and `not hasattr(litestar_security, 'InMemorySecurityBackend')`).
- [ ] **WST-05 (Store conformance parity without optional extras)**: Keep `InMemorySecurityBackend`, all 15 `StoreConformanceFactories` entries in `assert_security_backend_conformance`, and standalone `assert_rate_limiter_conformance` (`RateLimiter`) in lockstep with all store `Protocol` ports, importing and running without `argon2`, `pyotp`, `webauthn`, or `cbor2` installed.
- [ ] **WST-06 (Strict unit, integration, & typing test separation)**: Keep `src/tests/unit/` free of `Litestar`, `TestClient`, and `AsyncTestClient` instantiations, place ASGI, HTTP, CLI, and WebSocket app tests in `src/tests/integration/` (or `src/tests/examples/`), and keep `assert_type` checks in `src/tests/helpers/typing.py`.
- [ ] **WST-07 (Deterministic `FakeClock` & narrow fixture scoping)**: Use `FakeClock` instead of wall-clock sleeps for TTL/supervision tests, keep root fixtures (`clock`, `anyio_backend`, `jwt_key_material`) in `src/tests/conftest.py`, keep `src/tests/unit/conftest.py` scoped strictly to session-scoped `local_key_ring` and `src/tests/integration/conftest.py` as a docstring-only package anchor, and define single-module fixtures inside the test module that uses them.
- [ ] **WST-08 (`CORE_COVERAGE` 100% branch coverage on `_connect_tokens.py`)**: Maintain `100%` branch coverage on `src/litestar_security/websocket/_connect_tokens.py`.
