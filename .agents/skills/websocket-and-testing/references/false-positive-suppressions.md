# WebSocket & Testing False-Positive Suppressions

Do not flag the following intentional patterns in `src/litestar_security/websocket/`, `src/litestar_security/testing.py`, or `src/tests/`:

- **FP-WST-01 (Redacted one-time query-parameter connect-token extraction)**: Accepting a single-use, route/origin/epoch/policy-bound connect token via `WebSocketSecurityConfig.connect_token_query_parameter` (`"connect_token"` default) with `WebSocketHandshake.connect_token` marked `field(repr=False)` and `IssuedWebSocketConnectToken.__repr__` redacted is the intentional browser-compatible handshake carrier, while `RESERVED_QUERY_PARAMETERS` rejects reusable URL credentials (`access_token`, `authorization`, `bearer`, `jwt`, `token`).
- **FP-WST-02 (In-memory stores and deterministic test-kit doubles)**: `InMemorySecurityBackend`, `FakeClock`, `FakeOAuthProvider`, `InMemoryWebSocketRevocationSource`, and `_DeterministicProtector` in `src/litestar_security/testing.py` are test-kit utilities isolated from runtime imports (`R5`). Seeded `InMemoryOIDCSessionLogoutStore` fixtures (`oidc_logout_store` / `collaborators.build_security_environment()`) sit outside `collaborators.BACKEND_STORE_ATTRIBUTES`, and `StoreRateLimiter` (`RateLimiter`, verified via standalone `assert_rate_limiter_conformance`) sits outside `InMemorySecurityBackend.__slots__` and `StoreConformanceFactories`.
- **FP-WST-03 (Static type-check functions in `src/tests/helpers/typing.py`)**: Functions in `src/tests/helpers/typing.py` exist for `mypy` and `pyright` `assert_type` verification rather than runtime pytest assertions.
- **FP-WST-04 (Neutral fake credential strings in `src/tests/`)**: Test files use neutral dummy strings (`"fake-oauth-access-token"`, `b"k" * 32`, and targeted `# noqa: S105` / `# noqa: S106` comments on non-secret protocol tokens) so `prek` hooks (Ruff `S105`/`S106`, etc.) pass cleanly on intentional test fixtures.
- **FP-WST-05 (Direct `testing.py` exports & `_OAUTH_EXPORTS`-only `__getattr__`)**: `src/litestar_security/testing.py` exports all 15 conformance stores and suites directly in `__all__` so conformance runs without optional extras installed, while `src/litestar_security/__init__.py.__getattr__` resolves only `_OAUTH_EXPORTS` and leaves `litestar_security.testing` unimported (`R5`, enforced by Ruff `TID251` and `tools/check_import_boundaries.py`).
