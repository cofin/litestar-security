# Accounts Implementation Checklist

Verify each invariant when implementing or modifying `src/litestar_security/accounts/`:

- [ ] **ACC-01 (Enumeration resistance on login, recovery, & resend)**: Resolve identifiers via `AccountLookup.find_for_login`, run dummy `hasher.verify(None, password)` in `PasswordLoginService.authenticate` when an account is absent, and ensure `RecoveryTokenService.request` / `VerificationTokenService.resend` call `issue_absent()`, swallow store/delivery errors, and return uniform `202 Accepted` (`LifecycleAccepted`) responses.
- [ ] **ACC-02 (Dual-cookie session binding, `__Host-` invariants, & fixed expiry)**: Verify session binding cookies with `hmac.compare_digest`, enforce `secure=True`, `path="/"`, `domain=None` on `__Host-` cookies in `SessionBindingConfig._validate_binding_cookie_scope`, enforce `record.expires_at == authentication.expires_at` (no sliding `expires_at` renewal), and update `last_seen_at` only via `accounts.touch()` throttled by `touch_interval`.
- [ ] **ACC-03 (Refresh family reuse revocation & store-persisted AAD receipts)**: Revoke the full `family_id` (`RefreshRotationStatus.REPLAY_DETECTED`) when a rotated token is replayed without a valid `Idempotency-Key` header inside `receipt_window` (`<= timedelta(seconds=30)`), map `Idempotency-Key` via `RefreshTokenCodec.digest_idempotency_key` to store-persisted `sealed_receipt` bytes (`RefreshReceiptReplay`), and bind `RefreshReceiptSealer._receipt_aad` to `(account_id, expiry, family_id, idempotency, key_id, security_epoch, token_id, version="rr1")`.
- [ ] **ACC-04 (Domain-separated single-use purpose tokens vs. MFA challenges)**: Bind `TokenPurpose` (`INVITATION`, `VERIFICATION`, `RECOVERY`) into `PurposeTokenCodec` HMAC digests and consume atomically via `RegistrationStore.register`, `VerificationTokenStore.consume_and_verify`, and `RecoveryTokenStore.consume_and_reset`; handle password-login MFA challenges separately via `MFALoginService` (`MFALoginChallengeStore.consume`).
- [ ] **ACC-05 (At-rest TOTP encryption, peppered recovery codes, & Argon2 workers)**: Seal TOTP secrets with `AESGCMSecretProtector` into `ProtectedSecret(ciphertext: bytes, key_version: str)` (`nonce + ciphertext`, no `"v1:"` prefix), compute recovery-code HMAC digests with `RecoveryCodePepper` and delegate constant-time checking to `MFAStore.consume_recovery_code`, and offload `Argon2PasswordHasher` via `Argon2PasswordHasher._run_worker` using `WorkerLimits.crypto_limiter`.
- [ ] **ACC-06 (WebAuthn challenge consumption & sign-count clone-risk policy)**: Consume `WebAuthnChallenge` records once via `WebAuthnChallengeStore.consume` and detect clone risk only when `credential.sign_count > 0 and verified.sign_count <= credential.sign_count` (`CloneRiskPolicy.REJECT` rejects; `CloneRiskPolicy.AUDIT_ONLY` persists `clone_risk=True` and emits `OUTCOME_CLONE_RISK` without rejecting).
- [ ] **ACC-07 (Scoped single-use step-up grants)**: Persist `StepUpGrantState(grant_digest, transport_digest, principal_id, security_epoch, purpose, methods, traits, authenticated_at, expires_at)` using `clock: Callable[[], datetime]`, consume atomically via `StepUpStore.consume`, and return `AuthenticationEvidence(mechanism="step-up", slot="mfa", authenticated_at=record.authenticated_at, expires_at=record.expires_at, methods=record.methods, traits=record.traits | frozenset({f"purpose:{purpose}"}))`.
- [ ] **ACC-08 (`CORE_COVERAGE` 100% branch coverage on `_refresh.py`, controller test tiers, & store conformance)**: Maintain `100%` branch coverage on `src/litestar_security/accounts/_refresh.py`, cover pure `/auth` controller builders and helpers (`route_error`, `principal_id`, `require_local_bearer`, `build_local_auth_routes`, `build_mfa_routes`) in `src/tests/unit/test_accounts/test_controllers.py` (without `Litestar` or `TestClient`) alongside HTTP controller routes (including controller `_authorize_step_up`) in `src/tests/integration/test_accounts/test_controllers/`, and update `InMemorySecurityBackend` + `assert_security_backend_conformance` in `src/litestar_security/testing.py` whenever store protocols change.
- [ ] **ACC-09 (Optional-extra decoupling via `litestar_security.typing`)**: Keep pure protocols, records, `AESGCMSecretProtector`, `StepUpService`, `PasskeyService` (with custom `WebAuthnVerifier`), `LocalAuthConfig` (with custom `PasswordHasher`), and `controllers` executable without `argon2`, `pyotp`, or `webauthn` installed, keep `_CONTROLLER_EXPORTS` lazy in `accounts/__init__.py`, and gate only `Argon2PasswordHasher`, `MFAService`, `MFALoginService`, and `PyWebAuthnVerifier` at instantiation via `ensure_argon2` / `ensure_pyotp` / `ensure_webauthn`.
