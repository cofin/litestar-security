# Providers Implementation Checklist

Verify each invariant when modifying `src/litestar_security/providers/`:

- [ ] **PRV-01 (Explicit JWT algorithm allowlists & claim pinning)**: Require non-empty explicit algorithm allowlists in `JWTValidationConfig` (`EdDSA`, `ES256`, `RS256`, `HS256`), reject `alg="none"` and forbidden JOSE headers (`b64`, `crit`, `jku`, `jwk`, `x5c`, `x5t`, `x5t#S256`, `x5u`), require default `{"iss", "sub", "aud", "exp", "iat"}` (plus `client_id` and `jti` when `access_token_profile=True`), validate `nbf` when present, and enforce `typ` (`token_types`), `clock_skew`, and `maximum_lifetime`.
- [ ] **PRV-02 (`CompositeBearerConfig` & API-key Bearer prefix coordination)**: Route multi-issuer JWTs through `CompositeBearerConfig` / `extend_composite_bearer` with disjoint `BearerSlotSelector` (`issuers`, `audiences`, `token_types`), while keeping `APIKeyConfig(accept_authorization_bearer=True)` on `_APIKeyCredentialSlot` (`"api-key"` slot, `header_name.lower() != "authorization"`). Verify `AuthenticationRegistry._coordinate_bearer_slots` sets `excluded_prefixes` on `_BearerCredentialSlot` or wraps custom Bearer slots in `_PrefixExcludingBearerSlot`, and `_plan_uses_bearer` inspects `additional_security_schemes` (`APIKeyBearer`) for RFC 9728 `WWW-Authenticate: Bearer resource_metadata="..."` challenges.
- [ ] **PRV-03 (JWKS single-flight refresh & generation-scoped negative `kid` cache)**: Preserve lock-free fresh reads in `CachedJWKSProvider`, `asyncio.shield` single-flight refresh coalescing, `stale_if_error` grace windows, and generation-scoped negative `(kid, alg)` caching bounded by `JWKSCachePolicy.maximum_unknown_keys` (`1_024`) and cleared on snapshot generation bumps.
- [ ] **PRV-04 (API key HMAC digest, Bearer consistency, rotation overlap, & buffered usage)**: Validate a single 32+-byte `pepper` on `APIKeyCodec` and `APIKeyConfig`, compute domain-separated HMAC-SHA256 digests (`APIKeyProof`) compared via `hmac.compare_digest` against `APIKeyState.digest`, reject `header_name.lower() == "authorization"` unconditionally, reject conflicting `header_name` + `Authorization: Bearer <prefix>_...` tokens, enforce atomic `rotate` with bounded `overlap_until`, and verify `BufferedAPIKeyUsage` (`observe` drops when `len(_pending) >= capacity`; `close()`/`APIKeyService.close()` flushes with `force=True` to `APIKeyUsageSink.record`).
- [ ] **PRV-05 (Google IAP `ES256` pinning & machine/SPIFFE validation)**: Enforce `ES256`, issuer `https://cloud.google.com/iap`, `token_types={"JWT"}`, valid HTTP `header_name` (default `"X-Goog-IAP-JWT-Assertion"`), and exact audience strings in `GoogleIAPConfig`; ensure `GoogleIAPClaims.is_service_account` checks `external_identity is None`, `hosted_domain is None`, and exact `gserviceaccount.com` or `.gserviceaccount.com` domain; and ensure `GoogleIAPClaims.spiffe_id` rejects `external_identity`, `?`, `#`, whitespace/controls, empty or leading/trailing `.` authority, and empty, `.`, or `..` path segments (including trailing slashes).
- [ ] **PRV-06 (OAuth transaction sealing, PKCE, & redirect policy)**: HMAC-SHA256 digest `state` and `browser_binding` in `OAuthTransactionService`, validate exact `callback_uris` and `return_to` via `OAuthRedirectPolicy` (safe relative `/` non-`//` paths or exact HTTPS origins matching `callback_uris`), seal `pkce_verifier` and `nonce` with `OAuthTransactionProtector` (`AESGCMOAuthTransactionProtector`) in `MemoryOAuthTransactionStore`, bind PKCE `S256` and OIDC `nonce`, and consume atomically once via `OAuthTransactionStore.consume`.
- [ ] **PRV-07 (Outbound HTTPS & SSRF public-IP DNS defenses)**: Enforce HTTPS with `follow_redirects=False` and `trust_env=False`: `OAuthProviderClient._pinned_endpoint` resolves DNS and rewrites URL host to the literal public IP with `Host` and `extensions={"sni_hostname": hostname}` (no private-network opt-out); `HttpxJWKSFetcher` and `OIDCDiscoveryClient` (`DiscoveryPolicy`) reject non-public DNS IPs unless `allow_private_hosts=True` before streaming the original HTTPS URL, and enforce response byte and encoding limits.
- [ ] **PRV-08 (`CORE_COVERAGE` 100% branch coverage on JWT & OAuth transactions)**: Maintain `100%` branch coverage on `src/litestar_security/providers/jwt/*` and `src/litestar_security/providers/oauth/_transactions.py`, keeping outbound HTTP tests offline via `MockTransport`, `FakeOAuthHTTPTransport`, or `FakeOAuthProvider` with `FakeClock`.
