# Runtime & Policy Implementation Checklist

Use this checklist when implementing or modifying `SecurityPlugin`, `SecurityConfig`, `AuthenticationPolicy`, `RouteCompiler`, `AuthorizationPredicate` guards, `SecurityContext`, `WireDTO`, or `SecurityHeadersConfig`:

- [ ] **RUN-01 (`no_future_annotations`, runtime DI, & optional-extra decoupling)**: Omit `from __future__ import annotations` under `src/litestar_security/`; keep types referenced in Litestar route signatures, `Provide(...)` dependencies, or `WireStruct` fields imported at module scope; keep optional-extra shims in `_typing.py` (`typing.py`) with accurate `MissingDependencyError` `_EXTRAS` (`argon2->argon2`, `pyotp->mfa`, `webauthn->passkeys`) and eager annotation exports in `accounts/__init__.py` enforced at instantiation.
- [ ] **RUN-02 (Slotted contracts & `MappingProxyType` defaults)**: Use `@dataclass(frozen=True, slots=True)` on domain, evidence, snapshot, restriction, and immutable config types (`field(default_factory=lambda: MappingProxyType({}))` for read-only mapping defaults), `@dataclass(slots=True)` on mutable orchestrators (`SecurityConfig`, `RouteCompiler`, `PolicyCompiler`, `BlockingCallRunner`, `_PrefixExcludingBearerSlot`), and `__slots__` on non-dataclass runtime classes so `uv run slotscheck src/litestar_security/` passes.
- [ ] **RUN-03 (Restriction intersection & guard composition)**: Ensure `resolve_authorization` narrows `AuthorizationSnapshot` by `CredentialRestrictions(scopes, roles, capabilities, tenant_ids, resources)` without mutating `attributes`, and compose `guards.py` predicates through `requires_all_of`, `requires_any_of`, `requires_one_of`, `requires_at_least`, and `requires_assurance` (`_AssurancePredicate`).
- [ ] **RUN-04 (`public()` vs. `exclude()` CSRF, middleware, & OpenAPI parity)**: Ensure `public()` emits `[{}]`, initializes anonymous `scope["user"]` / `scope["auth"]`, and sets `opt[csrf_exclude_key] = True` unless `csrf_required=True` is set on the HTTP handler (required on cookie-establishing public routes), while `exclude()` emits `[{}]`, leaves native CSRF untouched unless `csrf_required=True`, and sets `plan.bypass_authentication=True` (`_handle_websocket` skips WebSocket handling).
- [ ] **RUN-05 (Single slot ownership, `_PrefixExcludingBearerSlot`, & RFC 9728 challenges)**: Enforce one owning mechanism per physical `CredentialSlot` (`"session"`, `"authorization.bearer"`, `"api-key"`, `"google-iap"`), wrap custom non-dataclass `authorization.bearer` slots in `_PrefixExcludingBearerSlot` during `_coordinate_bearer_slots`, and inspect both `security_scheme` and `additional_security_schemes` in `_plan_uses_bearer` for RFC 9728 `WWW-Authenticate` challenges.
- [ ] **RUN-06 (Static & runtime import boundaries)**: Keep runtime code free of `inspect.isawaitable` (`R4`: wrap sync ports in `BlockingIntegration` + `BlockingCallRunner`), `litestar_security.testing` imports (`R5` + `TID251`), and adapter dependencies (`TID251`); restrict `__init__.py` lazy loading via `_lazy.py` strictly to `_OAUTH_EXPORTS`.
- [ ] **RUN-07 (`WireStruct`, `WireDTO`, error schemas, & secret redaction)**: Subclass `WireStruct(frozen=True)` with `WirePolicy(rename, forbid_unknown_fields)` (`MAX_NESTED_DEPTH = 4`), bind `cache_key = (*name_key, shape)` before indexing `_transfer_models`, keep `WireUnionDTO` / `union_wire_dto` response-only, restate raised denials via `ProblemDetailsPlugin(enable_for_all_http_exceptions=True)` (`ProblemDetail`) or `RaisedErrorSchema` (default `RouteError`), and redact secrets via `SecretStr`, `field(repr=False)`, or custom `__repr__`.
- [ ] **RUN-08 (Security headers & `__Host-` binding cookie validation)**: Wire `SecurityHeadersConfig` / `ContentSecurityPolicy` through `configure_security_headers` (`response_headers`, `before_send`, `csp_nonce` DI — never middleware), validate `CSRFConfig` / `ExternalCSRF` exclusions, and enforce `__Host-` (`secure=True, path="/", domain=None`) invariants on `SessionBindingConfig` and `OAUTH_BINDING_COOKIE_NAME`.
- [ ] **RUN-09 (`CORE_COVERAGE` 100% branch coverage & test tier boundaries)**: Cover all branches in `authentication.py`, `guards.py`, and `context.py`, placing pure unit tests in `src/tests/unit/` (without instantiating `Litestar`, `TestClient`, or `AsyncTestClient`) and ASGI tests in `src/tests/integration/`.
