# Runtime & Policy False-Positive Suppressions

Do not flag the following intentional patterns in `src/litestar_security/`:

- **FP-RUN-01 (Runtime imports in controller, plugin, and `accounts/__init__.py` modules)**: Module-top imports of `Request`, `ASGIConnection`, `SecurityContext`, `Principal`, `WireStruct` subclasses, and `Argon2PasswordHasher` / `MFAService` / `MFALoginService` / `PyWebAuthnVerifier` are required at runtime for Litestar signature and DTO evaluation because `from __future__ import annotations` is banned in `src/litestar_security/`; optional-extra enforcement happens at instantiation.
- **FP-RUN-02 (Default CSRF exclusion on `public()` routes without `csrf_required=True` vs. untouched `exclude()` routes)**: `public()` intentionally sets `opt[csrf_exclude_key] = True` unless `csrf_required=True` is explicitly passed on the HTTP handler (cookie-establishing public routes such as `/auth/login` pass `csrf_required=True`), whereas `exclude()` leaves Litestar's native CSRF middleware untouched unless `csrf_required=True` is set.
- **FP-RUN-03 (`__getattr__` + `_lazy.py` in `src/litestar_security/__init__.py`)**: `__init__.py` uses `_lazy.py` (`import_optional_attribute`) solely to defer `_OAUTH_EXPORTS` from `litestar_security.providers`; `litestar_security.testing` (`InMemorySecurityBackend`, `FakeClock`) is never exported by `__init__.py` and its isolation (`R5`) is enforced by Ruff `TID251` and `tools/check_import_boundaries.py`.
- **FP-RUN-04 (`anyio.to_thread.run_sync(..., abandon_on_cancel=False)` in `BlockingCallRunner`)**: `abandon_on_cancel=False` is intentional so cancelled requests wait for bounded sync worker completion rather than leaking orphan threads mutating shared state.
- **FP-RUN-05 (Mutable `@dataclass(slots=True)` on runtime orchestrators and slots)**: `SecurityConfig`, `RouteCompiler`, `PolicyCompiler`, `BlockingCallRunner`, and `_PrefixExcludingBearerSlot` intentionally omit `frozen=True` while preserving `slots=True` because they accumulate or bind runtime state.
- **FP-RUN-06 (Local `cache_key = (*name_key, shape)` assignment in `WireBackend`)**: Binding `cache_key` before subscripting `cls._transfer_models[cache_key]` in `src/litestar_security/_dto.py` is required for Python 3.10 `mypy` (`ast-serialize`) compatibility so starred unpacking is not parsed as PEP 646 subscript slice syntax.
