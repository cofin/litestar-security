Contributing
============

Litestar Security uses test-driven development and Conventional Commits. Keep
changes focused on an approved contract, and do not introduce authentication or
authorization behavior as incidental scaffold work.

The essential commands are:

.. code-block:: console

   make install
   make test
   make coverage
   make type-check
   make lint
   make docs
   make docs-linkcheck
   make build

The complete contributor guide is available in the repository's
``CONTRIBUTING.rst`` file.
